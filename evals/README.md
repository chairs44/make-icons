# Evaluate the skill

Use three realistic cases: structural reference reproduction (home/scissors), organic reference reproduction (sprout/heart), and transfer to new audio subjects (field recorder/tape loop). Use your own supplied references. Keep them and raw run traces outside the distributed package.

For each case, run the same brief, input files, output scope, model, reasoning settings, and tool availability in fresh isolated workspaces. Compare a baseline with this skill disabled at runtime, the current skill, and a revised candidate. Snapshot each treatment before running. Do not let the baseline read the skill or treatment outputs. Verify the skill catalog before running and actual skill-file reads in the trace afterward. A final self-report is supporting evidence, not a substitute for a trace.

Capture SVGs, light/dark actual-size renders, enlarged reference pairs, desktop/mobile comparison screenshots, exit status, and check results. Keep invalid-input or failed runs with a reason; exclude them from scored comparisons. Retry only with the same corrected inputs across treatments.

Grade identity/topology first, then reference proportions, terminals/curves, optical balance, and small-size recognition. Record concrete observations per icon; a fatal semantic error cannot be averaged away by valid XML. Use image similarity only as a diagnostic. Have a separate reviewer inspect anonymized renders where available, then disclose treatment labels. The user remains the judge of preferred visual direction.

Also probe activation: an explicit skill request, an implicit SVG icon request, a contextual icon-edit request, and unrelated copy/arithmetic/code tasks. Record whether the skill was loaded. Distinguish routing success from drawing success.

A three-case pilot with one run per treatment is exploratory. It cannot prove perfection or robustness across models. Repeat representative cases when the results are inconsistent or the skill changes materially. Keep the full experiment report outside the public skill unless publication of its references and traces is intended.
