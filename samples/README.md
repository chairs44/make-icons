# Make Icons samples

Ten editable outline SVGs: home, camera, headphones, plant, ticket, book, coffee cup, scissors, backpack, and cassette. Each uses a native 24-unit grid and a nominal 1.5-unit stroke, with custom filled contours for the scissors blades. The banner, construction examples, and sample archive use these exact drawings.

Open preview.html for 16/20/24/32px displays, a 72px detail, text pairing, and both polarities. These are scaled displays of the same masters, not separately tuned compact drawings. Cassette reel holes and narrow handle openings are least distinct at 16px. The plant is a sprout without a pot.

Files use currentColor and transparent negative space. Label icon-only controls on their parent; add accessible names for meaningful standalone images. MIT licensed; see LICENSE.

Validation checks SVG structure and package consistency. Rendered inspection covers the displayed sizes and both polarities; it does not certify a future application integration. See manifest.json for recorded checks.
