# Make Icons samples

Sixteen original outline SVGs on a native 24-unit grid with a 1.5-unit stroke. The showcase and archive use these exact files. Open preview.html for 16/20/24/32px scaled samples and enlarged views in both polarities. These are not separately tuned compact masters. Dense subjects are clearest at 24px or larger.

Files use currentColor and transparent negative space. Label icon-only controls on their parent; add accessible names when using icons as meaningful standalone images. MIT licensed; see LICENSE.
