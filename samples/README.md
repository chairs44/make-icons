# Make Icons samples

Ten original outline SVGs: home, camera, headphones, plant, ticket, book, coffee cup, scissors, backpack, and cassette. Each uses a native 24-unit grid and a 1.5-unit stroke. The banner, construction examples, and sample archive use these exact drawings.

Open preview.html for 16/20/24/32px displays, a 72px detail, text pairing, and both polarities. These are scaled displays of the same masters, not separately tuned compact drawings. Cassette reel details and narrow handle openings are least distinct at 16px.

Files use currentColor and transparent negative space. Label icon-only controls on their parent; add accessible names for meaningful standalone images. MIT licensed; see LICENSE.

Validation checks SVG structure and package consistency. Rendered inspection covers the displayed sizes and both polarities; it does not certify a future application integration. See manifest.json for recorded checks.
